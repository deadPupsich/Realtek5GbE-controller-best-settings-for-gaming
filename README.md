# Realtek5GbE-controller-best-settings-for-gaming

> **Главное правило:** Ребут пк или ребут драйвера

---

## 1. Энергосбережение и «Зеленые» технологии
*   **Advanced EEE** → `Отключено` (Убирает микрозадержки при переходе в спящий режим). Для игр неприменимо и разницы не будет.
*   **EEE Max Support Speed** → `Любое`. Не важно, тк отключили `Advanced EEE`
*   **Gigabit Lite** → `Отключено` (Принудительное снижение скорости для экономии энергии)
*   **Power Saving Mode** → `Отключено`. PSM у меня вызывал лоссы.
*   **Selective Suspend** → `Отключено` (Еще один механизм энергосбережения)
*   **Зеленый Ethernet (Green Ethernet)** → `Отключено`
*   **Энергосберегающий Ethernet (EEE)** → `Отключено`

## 2. Разгрузка (Offload) и обработка пакетов
*   **Модерация прерывания (Interrupt Moderation)** → `Отключено` (Убирает накопление пакетов). -инпутлаг)
*   **Разгрузка при большой отправке v2 (IPv4/IPv6)** (Large Send Offload) → `Отключено` (Склейка пакетов добавляет задержку в теории, тестил, ноль изменений).
*   **Выгрузка протокола ARP** → `Отключено`. ARP реклама юзлесс, в теории убирает микрозадрежки, зависит от драйвера
*   **Выгрузка протокола NS** → `Отключено`. В теории убирает микрозадрежки, зависит от драйвера
*   **Контрольная сумма разгрузки TCP (IPv4/IPv6)** → `Оставить включенным (Rx & Tx Enabled)` (Разгружает CPU, на пинг не влияет)
*   **Контрольная сумма разгрузки UDP** → `Оставить включенным (Rx & Tx Enabled)` (Аналогично TCP)
*   **Управление потоком (Flow Control)** → `Отключено` (Иногда вызывает фризы, если роутер тоже пытается управлять потоком)

## 3. Буферы и очереди (Баланс скорости и отклика)
*   **Буферы приема (Receive Buffers)** → `128` Receive Buffers и Transmit Buffers рекомедую тестить, сильно зависит от реализации встройки на конкретной мамке, слишком низкие могут вызывать packet loss
*   **Буферы передачи (Transmit Buffers)** → `128` (256 баланс, 512 для стабильности при фоновой загрузке)
*   **Максимальное число очередей RSS** → `Оставить по умолчанию` (Обычно 2, 4, 8, т.к. в теории само подтягивает кол-во ядер проца и разбивает по ним, незначительно)
*   **Получение бокового масштабирования (RSS)** → `Оставить включенным`

## 4. Прочее (Сеть и адресация)
*   **Большой кадр (Jumbo Frame)** → `Отключено` (Бесполезно для интернета, только вредит)
*   **Скорость и дуплекс (Speed & Duplex)** → `Автосогласование (Auto Negotiation)`. Можно форсировать в `5.0 Гбит/с дуплекс`, если не возникнет проблем со стабильностью и хороший кабель.
*   **Приоритет & VLAN** → `Оставить по умолчанию` (Отключено или «Приоритет & VLAN»)
*   **Сетевой адрес** → `Не задан (Not Present)` (Использовать заводской MAC)
*   **Включение по локальной сети... (Wake on Magic Packet)** → `Отключено`. По необходимости.
*   **Включить при совпадении шаблона** → `Отключено`
*   **Включить при срабатывании функций** → `Отключено`
*   **Скорость при включении по локальной сети** → `Отключено` (или по умолчанию)
